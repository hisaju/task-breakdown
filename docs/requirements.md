# 要件定義

## 1. ペルソナ

### メインペルソナ：新入社員
- 社会人 1 年目。仕事の進め方や必要な時間を、まだ予測できない
- 指示は「見積もり作っておいて」「起案書出しておいて」のように大まかに受け取る
- タスクを大分類のまま ToDo に登録し、空いた時間に着手する

### 対比：ベテラン社員
- 同じタスクを**着手できる手順**に分解する
- 他者の返答待ち・承認待ちが発生する工程を先に済ませる
- 期限から逆算して各手順の期限を決める

### 事例

| 事例 | 新入社員 | ベテラン社員の分解 | ポイント |
|---|---|---|---|
| 営業：見積もり作成 | 「見積もり作成」をそのまま登録し、空いた時間に対応。対応が遅れて残業 | ①仕入れ先へ見積依頼 ②見積作成 ③見積提出 | 16 時帰社から逆算し、15 時までに仕入れ先へ依頼。当日中に提出 |
| 社内業務：起案書 | 「起案書作成」だけを登録。提出直前に慌てて対応 | ①決裁基準の確認 ②必要書類準備 ③起案書作成 ④管理部事前確認 ⑤上司承認 ⑥起案書申請 | 情報収集・関係者確認・上司への事前相談を含め、期限から逆算 |
| 社内業務：経費申請 | 「経費申請」だけを登録。領収書不備・書類不足に気づくのが遅れる | ①領収書準備（Web 申請なら写真撮影）②勘定科目の事前確認 ③経費申請の入力 ④経費申請 | 不備があった場合の修正時間も考慮して余裕を持って申請 |

## 2. ユースケース

### MVP

| ID | ユースケース | 概要 |
|---|---|---|
| UC-1 | タスクの入力 | 達成したい大元のタスク（親タスク）を入力する |
| UC-2 | タスクの分解 | 入力したタスクが、AI によって実行可能な粒度のサブタスクに分解される |
| UC-3 | タスクの手動追加 | 分解結果に対し、ユーザーが独自のサブタスクを追加できる |
| UC-4 | 期限の個別設定 | 各サブタスクに、それぞれ個別の期限を設定できる |
| UC-5 | 完了タスクの非表示化 | タスクを完了にすると一覧から非表示になる。「完了済みを表示」で再表示できる |
| UC-6 | 期限順の一覧表示 | 「マイタスク」で親タスク（大カテゴリ）が期限の近い順に並ぶ。期限未設定の親タスクも末尾で確認できる。サブタスクはタスク詳細の日付タブで期限ごとに確認する |
| UC-7 | 会員登録・ログイン | メールアドレスとパスワードで登録・ログインし、自分のタスクだけを扱う |

### 拡張

| ID | ユースケース | 概要 |
|---|---|---|
| UC-8 | 分解の調整（再生成） | 「再分解」「もっと細かく」「もっとざっくり」で分解をやり直す |
| UC-9 | 進捗の可視化 | サブタスクの完了数に応じて親タスクの進捗を「n/m 完了」とプログレスバーで表示する（例：3/5 完了） |

## 3. ユーザーストーリー

> わたしは**新入社員**として、**曖昧な指示を具体的な手順に分解したい**。
> なぜなら、**何から手をつければいいか迷う時間をなくし、仕事をスムーズに終わらせて早く帰りたい**からだ。

### 派生ストーリー
- 新入社員として、**他の人の確認や承認が必要な手順を先に知りたい**。待ち時間で期限に間に合わなくなるのを防ぎたいからだ。
- 新入社員として、**今日やるべき手順だけを見たい**。複数のタスクを抱えていても、次の一手に迷わないためだ。
- 新入社員として、**AI の分解に自分の知っている手順を足したい**。職場固有のルールを反映したいからだ。

## 4. 受入条件

### UC-1 タスクの入力
- [ ] 「タスクを作る」画面で、自由文（最大 200 文字）を入力して送信できる
- [ ] 入力例のチップを押すと、入力欄に例文が入る
- [ ] ⌘ + Enter（Windows は Ctrl + Enter）で送信できる
- [ ] 空欄では送信できない

### UC-2 タスクの分解
- [ ] 送信後、タスク詳細画面に遷移し、分解中であることが表示される
- [ ] 30 秒以内に 3〜8 件のサブタスクが表示される（画面の再読み込みは不要）
- [ ] 各サブタスクは「タスク名」「補足説明」「種別（基本タスク／特殊タスク）」「期限」を持つ
- [ ] 他者の確認・承認・返答待ちが発生するサブタスクは「特殊タスク」として区別される
- [ ] 親タスクに期限がある場合、各サブタスクの期限は親タスクの期限を超えない
- [ ] 分解に失敗した場合はエラーを表示し、再実行できる

### UC-3 タスクの手動追加
- [ ] タスク詳細画面の「タスクを追加」から、サブタスクを末尾に追加できる
- [ ] 追加した直後に、そのカードでタスク名・補足を入力できる
- [ ] 追加したサブタスクは、タスク名・説明・期限を編集できる

### UC-4 期限の個別設定
- [ ] 各サブタスクに日時で期限を設定・変更・解除できる
- [ ] 期限は時刻付き（今日 17:00／明日 12:00／11/1 17:00）で表示され、未設定のときは「期限なし」と表示される

### UC-5 完了タスクの非表示化
- [ ] サブタスクの丸いチェックを押すと完了になり、一覧から消える
- [ ] 「完了済みを表示」を押すと、完了済みのタスクが打ち消し線付きで表示される
- [ ] 完了済みのタスクは未完了に戻せる

### UC-6 期限順の一覧表示
- [ ] 「マイタスク」画面に、自分の親タスク（大カテゴリ）が期限の近い順に並ぶ
- [ ] 日付ごとに見出しで区切られ、期限未設定の親タスクは末尾の「期限なし」にまとまる
- [ ] 各親タスクには期限と進捗（例：2/5 完了）が表示され、選ぶとタスク詳細へ遷移する
- [ ] すべてのサブタスクが完了した親タスクは完了扱いとなり、既定では表示されない（「完了済みを表示」で再表示）
- [ ] タスク詳細画面では、サブタスクが期限の近い順に並び、日付タブ（すべて／今日／明日／M/D）で絞り込める。期限未設定のサブタスクは末尾に表示される

### UC-7 会員登録・ログイン
- [ ] お名前・メールアドレス・パスワード（8 文字以上）で会員登録できる
- [ ] 利用規約とプライバシーポリシーへの同意が必須
- [ ] メールアドレスとパスワードでログインでき、ログアウトできる
- [ ] ログインしていない場合はログイン画面へ遷移する
- [ ] 他のユーザーのタスクは表示・操作できない

### UC-8 分解の調整（拡張）
> 画面モックでは、タスク詳細の親タスクのメニューに「再分解」だけを置く（見た目のみ）。「もっと細かく」「もっとざっくり」は拡張として後から加える。

- [ ] 「再分解」「もっと細かく」「もっとざっくり」を選んで分解をやり直せる
- [ ] やり直し時、手動で追加したサブタスクと完了済みのサブタスクは残る

### UC-9 進捗の可視化（拡張）
- [ ] 親タスクの進捗が「n/m 完了」（例：3/5 完了）とプログレスバーで表示される

## 5. 非機能要件

| 項目 | 要件 |
|---|---|
| 応答性能 | 画面遷移は 1 秒以内。AI 分解は非同期で行い、30 秒以内に完了する |
| セキュリティ | パスワードはハッシュ化して保存。他ユーザーのデータにはアクセスできない。API キーは環境変数で管理し、リポジトリに含めない |
| 対応ブラウザ | 最新版の Chrome / Edge / Safari（PC） |
| 可用性 | AI API の障害時も、タスクの手動登録・編集・完了は利用できる |
